# AI搭載 QA自動生成・学習分析システム

講義内容のテキストや資料（PDF/PPTX）から、AIが自動で多様な形式の確認問題（QA）を生成し、学習者の解答状況を詳細に分析・可視化するためのWebアプリケーションです。

---

## 🚀 主な機能

このシステムは、問題を作成する「管理者」と、問題に解答する「学習者」の2つの役割を想定しています。

### **管理者向け機能**
- **AIによるQA自動生成:**
  - テキストを直接入力、または講義資料（PDF, PowerPoint）をアップロードすることで、AIが内容を理解しQAを生成します。
  - 生成する問題数は、手動での指定と、AIによる自動調整が可能です。さらに「AIにおまかせ」モードでは、プロンプトを自由記述することで、生成されるQAの方向性をコントロールできます。
- **多様な問題形式と難易度:**
  - 4択問題、複数選択問題、自由記述問題など、多様な形式の問題を自動で作成します。
  - 生成する問題セット全体の難易度（簡単・普通・難しい）を指定できます。
- **QAデータの管理:**
  - 生成された全ての問題（問題文、選択肢、正解、解説、配点など）を後から手動で編集・削除できます。
- **成績分析ダッシュボード:**
  - 学習者全体の成績と、個人別の成績を切り替えて分析できます。
  - **得点率の可視化:** 問題ごとの得点率を棒グラフで表示。個人成績と全体平均を比較できます。
  - **統計指標:** 学生ごとの平均得点率や偏差値を自動で算出・表示します。
  - **フィードバック分析:** 学習者が提出した講義への満足度評価（5段階）や自由記述コメントを確認できます。
- **AIによる統合分析機能:**
  - **自動分析レポート:** 得点率、講義への満足度評価、自由記述コメントといった全てのデータをAIが統合的に分析し、講義内容や設問に関する客観的な「総合評価」と、具体的な「改善点の提案」を自動で生成します。
  - **カスタム分析:** 定型レポートだけでなく、管理者が「最も正答率が低い問題の理由は？」といった自由な質問をAIに投げかけ、対話的にデータを深掘りできるモードも搭載しています。
- **セキュリティ:**
  - 管理者ページはパスワードで保護されています。

### **学習者向け機能**
- **シンプルな学習フロー:**
  - ログイン（ユーザー選択）、テスト開始、解答、結果確認、復習という一連の流れを直感的に操作できます。
- **インタラクティブな解答画面:**
  - 問題形式に合わせて、ラジオボタン、チェックボックス、テキストエリアなど、最適なUIで解答できます。
- **AIによる自動採点:**
  - テスト完了後、一括で採点が行われます。
  - **部分点評価:** 自由記述問題は、AIが模範解答との近さを評価し、部分点を考慮した採点を行います。
- **詳細な結果・復習:**
  - テスト全体の合計点と満点を表示。
  - 問題ごとに、自身の解答、正解、AIによるフィードバックや解説を確認し、効果的な復習が可能です。
- **再挑戦機能:**
  - 一度解いたテストに再度挑戦できます。（再挑戦の成績は、全体の分析データには影響しません）
- **講義へのフィードバック:**
  - 初回テスト完了時に、5段階の満足度評価と自由記述コメントを提出できます。

## 🛠️ 使用技術

- **言語:** Python 3.10
- **フレームワーク:** Streamlit
- **AIモデル:** OpenAI API (GPT-4o)
- **データ分析・可視化:** Pandas, NumPy, Matplotlib, japanize-matplotlib
- **ファイル処理:** PyPDF, python-pptx
- **データベース:** SQLite3
- **バージョン管理:** Git, GitHub

## ⚙️ セットアップと実行方法

このプロジェクトをローカル環境で実行するための手順です。

### 1. リポジトリのクローン
```bash
git clone [https://github.com/aobu04/lecture-ai-engineering.git](https://github.com/aobu04/lecture-ai-engineering.git)
cd lecture-ai-engineering
```

### 2. 仮想環境の構築と有効化
```bash
# 仮想環境を作成
python3 -m venv venv

# 仮想環境を有効化 (macOS/Linux)
source venv/bin/activate

# 仮想環境を有効化 (Windows)
# venv\Scripts\activate
```

### 3. 必要なライブラリのインストール
```bash
pip install -r requirements.txt
```

### 4. シークレット情報の設定
プロジェクトのルートに `.streamlit` というフォルダを作成し、その中に `secrets.toml` というファイルを作成します。ファイルに以下の内容を記述し、ご自身の情報に置き換えてください。

```toml
# .streamlit/secrets.toml

ADMIN_PASSWORD = "（管理者ページのログインパスワード）" 
OPENAI_API_KEY = "sk-（あなたのOpenAI APIキー）"
```

### 5. アプリケーションの実行
```bash
streamlit run app.py
```
実行後、ブラウザで表示されたURL（通常は http://localhost:8501）にアクセスしてください。
